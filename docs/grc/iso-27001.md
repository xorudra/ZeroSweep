# ISO/IEC 27001:2022 in ZeroSweep (Prompt 26)

Shipped catalog version: ISO_27001 2022 (Annex A themed structure,
clauses 4–10 management requirements + Annex A themes 5–8).
Requirement IDs/titles are the published reference structure;
full licensed framework text is **not** bundled — organizations
import their licensed content via the framework import API.

ZeroSweep's relationship to ISO 27001:

- Controls map across Annex A themes: organizational (A.5: MFA
  context A.5.17, asset management A.5.9, logging A.5.15 context,
  access review A.5.15, vendor A.5.19, incident A.5.24–5.28),
  people (A.6: training A.6.3), physical (A.7: manual evidence),
  technological (A.8: vulnerability management A.8.8, logging
  A.8.15 evidence, backup A.8.13, cryptography A.8.24, secure SDLC
  A.8.25–8.31, change A.8.32).
- Technical requirements (A.8.x especially) receive automated
  evidence from scans, posture and identity signals. Management-
  system requirements (clauses 4–10, A.5.35 independent review,
  A.6.3 training) are administrative/manual-evidence requirements.
- Assessment results are evidence-based states. **ZeroSweep does not
  certify ISO 27001 compliance**; certification is by accredited
  certification bodies only.
