# Binary Ninja (Prompt 18 §38/§96)

Optional **commercial connector** with the same license-aware health
contract as IDA (`NOT_INSTALLED` / `INSTALLED` /
`LICENSE_UNAVAILABLE` / `READY` / `NOT_CONFIGURED`). Never bundled,
license never bypassed, and the baseline works without it. In this
build no installation is provisioned, so the connector honestly
reports `NOT_CONFIGURED`.
