# GDB (Prompt 18 §65/§66)

GDB is a **governed descriptor, DISABLED outside LAB**. It exists
only inside the BinaryDebugPolicy: LAB environment, authorized
artifact, VERIFIED target, separate approval, isolated worker,
NO_NETWORK default, hard timeout, kill switch, typed operations
only. There is no executing adapter in this build and no way to pass
a GDB command, Python snippet or shell text through the API
(§68/§93/§114).
