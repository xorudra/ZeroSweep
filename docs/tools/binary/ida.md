# IDA (Prompt 18 §37/§96)

Optional **commercial connector**. License-aware health:
`NOT_INSTALLED` / `INSTALLED` / `LICENSE_UNAVAILABLE` / `READY` /
`NOT_CONFIGURED`. IDA is never bundled, its license is never
bypassed, IDAPython from users is never accepted (§93), and imported
reports are parsed through the same bounded inventory parser as
Ghidra's. The baseline open-source pipeline works fully without it.
In this build no installation is provisioned, so the connector
honestly reports `NOT_CONFIGURED`.
