# ADExplorer

**Posture:** MANUAL — analysis aid, import only (Prompt 15)

ADExplorer (Sysinternals) is a manual analyst tool (§56). The
platform never executes it; its snapshot exports import through the
guarded directory import path (bounded parsing, credential
stripping, hostile-content sanitization) and merge into the
identity graph with `adexplorer` provenance.
