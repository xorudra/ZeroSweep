# User Guide (Prompt 40 §155)

Audience: analysts and organization OWNER/ADMIN/MEMBER roles.

- **Assessments & scans** — governed lifecycle: verified target →
  scope → assessment → approval → scan (see getting-started).
- **Findings** — triage states, evidence handling, SLA timers
  (Prompt 31), remediation tickets and verification retests.
- **Reports** — generation, redaction, approval workflow, client
  portal publication and share links (Prompt 37).
- **Settings** —
  [Usage](../product/limits.md) (`/settings/usage`): measured usage +
  quota state (§107);
  Plan (`/settings/plan`): entitlements, upgrade/downgrade with impact
  preview (§113–§118);
  Billing (`/settings/billing`): provider state, invoices, events —
  honest NOT_CONFIGURED when no provider exists (§109);
  License (`/settings/license`): license status + install (§110).
- **Capabilities page data** — a feature can be NOT_ENTITLED,
  NOT_DEPLOYED, WORKER_UNAVAILABLE or QUOTA_EXCEEDED; the state shown
  is computed live (§119–§121), not a static plan table.
