# First Workspace (Prompt 40 §154)

- Signup already created a default workspace. Rename it under
  Organization → Workspaces, and invite your team (Organization →
  Members). Invitations use hashed, single-use, expiring tokens and a
  role never exceeds the inviter's own role (§76–§79).
- Workspaces isolate assessments, assets and reports inside your
  organization. Tenant isolation is enforced server-side on every
  request (§133).
