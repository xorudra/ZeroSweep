# Incident Communication Workflow (Prompt 40 §165)

1. **Detect & declare** — operator confirms impact from measured
   health/metrics; declare severity and affected components.
2. **Post initial notice** — status page updated with components,
   impact and next-update time. No speculation about cause.
3. **Update on cadence** — at the promised times, even if the update
   is "still investigating". Tenant-impacting incidents also notify
   organization OWNER/ADMIN contacts (notification preferences, §152).
4. **Resolve** — mark resolved only when measured health confirms it.
5. **Post-incident summary** — timeline, root cause, customer impact,
   remediation. Published by the operator; never auto-generated
   fiction.
