# DSRclone — product truth

**What it is:** a GUI-first, authorized automated VAPT platform. Users add targets they own, prove ownership, plan an assessment, get it approved, run safe scans through tool adapters, read normalized findings worst-first, and download reports. Nothing scans an unverified target or an unapproved assessment — that gate is the product's legal spine.

**Who uses it:** the owner-operator (Rudra) daily, plus invited workspace members. One workspace today ("Rudra Workspace"). Solo use must work end to end: every user can create, verify, approve and run their own work (owner order 2026-10-21, "zero restriction").

**The road (the product's one path):** Target → Verify → Assessment → Approve → Scan → Findings → Report. The home screen exists to answer "where am I on the road, and what is the next step?" Everything beyond the road is advanced tooling, present but quiet.

**Voice:** plain words, no jargon theatre. Numbers are real or shown as absent — never invented. Demo data is labelled demo.

**Surfaces:** web console (Next.js), dark, desktop + phone. Mode: Operate.
